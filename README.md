# Solar System Explorer

Монорепозиторій інтерактивного застосунку для перегляду планет Сонячної системи. До складу проєкту входять вебверсія та мобільний застосунок зі спільними пакетами для API, стану, оформлення й конфігурацій.

## Можливості

- Відображення Сонця, восьми планет та їхніх орбіт.
- Пересування планет уздовж власних орбіт перетягуванням.
- Перегляд вибраної планети, її координат, знака та напрямку руху.
- Оновлення астрономічних даних із FreeHoroscopeAPI.
- Перемикання світлої та темної тем оформлення.
- Спільний Redux Toolkit store для веб- і мобільної версій.

## Структура проєкту

```text
apps/
  web/       Вебзастосунок на Next.js
  mobile/    Мобільний застосунок на Expo та React Native
packages/
  api/       API-клієнт і типи даних планет
  store/     Redux Toolkit store, slices та обчислення орбіт
  ui/        Дизайн-токени, графіка планет і спільний Tailwind/NativeWind preset
  config/    Спільні конфігурації TypeScript, ESLint і Prettier
```

Пакети `api`, `store` та `ui` підключені до обох застосунків через workspace-залежності. Стан планет, завантаження даних, вибрана планета й тема оформлення зберігаються у спільному store.

## Технології

- **Веб:** Next.js, React, TypeScript, Tailwind CSS.
- **Мобільний застосунок:** Expo, React Native, Expo Router, NativeWind, TypeScript.
- **Спільний стан:** Redux Toolkit і React Redux.
- **Орбіти та жести:** власні обчислення координат, `@dnd-kit` у вебверсії та Gesture Handler із Reanimated у мобільній.
- **Дані планет:** FreeHoroscopeAPI, запит sidereal zodiac.
- **Пакетний менеджер:** pnpm workspaces.

## Вимоги

Для встановлення залежностей потрібні Node.js і pnpm. Версія pnpm, зазначена в конфігурації проєкту: `12.21.0`.

## Встановлення

Команда виконується з кореневої директорії монорепозиторію:

```bash
pnpm install
```

## Запуск застосунків

### Вебверсія

```bash
pnpm dev:web
```

Після запуску вебзастосунок доступний за адресою `http://localhost:3000`.

### Мобільний застосунок

```bash
pnpm dev:mobile
```

Запускається Expo development server. Інструкції для відкриття застосунку на пристрої або емуляторі відображаються в терміналі.

Окремий запуск для конкретної платформи:

```bash
pnpm --filter mobile android
pnpm --filter mobile ios
pnpm --filter mobile web
```

## Додаткові команди

Перевірка та збірка вебверсії:

```bash
pnpm --filter web lint
pnpm --filter web build
```

Перевірка мобільного застосунку:

```bash
pnpm --filter mobile lint
```
